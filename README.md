# Site-Itinerario-TI-Conteudos-ENEM
Portal educacional desenvolvido com HTML5 e CSS3, reunindo projetos escolares das disciplinas de Matemática, Biologia e Química. Possui páginas individuais, navegação intuitiva e cards interativos com efeitos de hover e imagens temáticas, facilitando a organização e divulgação dos trabalhos dos alunos.
